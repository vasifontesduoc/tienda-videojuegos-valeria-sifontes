# 🎮 Tienda de Videojuegos — Valeria Sifontes

Repositorio del proyecto semestral de **Desarrollo Frontend I (PFY2201)**, Duoc UC.

Contiene la tienda de videojuegos online que se desarrolló semana a semana durante el curso, hasta la **Evaluación Final Transversal (EFT)**.

- **Sitio publicado (EFT):** https://vasifontesduoc.github.io/tienda-videojuegos-valeria-sifontes/tienda-videojuegos-react/
- **Autora:** Valeria Sifontes
- **Docente:** Alonso Castillo

## Contenido del repositorio

| Carpeta | Descripción |
| ------- | ----------- |
| [`tienda-videojuegos-react/`](tienda-videojuegos-react/) | **Proyecto final (EFT).** Hecho con React, Vite y Bootstrap 5: catálogo dinámico, filtro por categoría, agregar y eliminar videojuegos, carrito y formulario de contacto validado. Las instrucciones de instalación y uso están en su [README](tienda-videojuegos-react/README.md). |
| [`tienda-videojuegos-s6/`](tienda-videojuegos-s6/) | Versión de la Semana 6, hecha con HTML, CSS, Bootstrap 5 y JavaScript puro. Genera las tarjetas manipulando el DOM directamente (`createElement`, `appendChild`, `addEventListener`) y carga los productos con la Fetch API. |

## Inicio rápido (proyecto EFT)

```bash
git clone https://github.com/vasifontesduoc/tienda-videojuegos-valeria-sifontes.git
cd tienda-videojuegos-valeria-sifontes/tienda-videojuegos-react
npm install
npm run dev
```

Luego abre en el navegador la dirección que aparece en la terminal (por ejemplo `http://localhost:5173/...`).

**Requisitos:** Node.js 20 o superior y Git.

## Evolución del proyecto

| Etapa | Contenido |
| ----- | --------- |
| Semanas 1 a 4 | Maquetación con HTML5, CSS y Bootstrap 5 |
| Semana 5 | JavaScript: manipulación del DOM y eventos |
| Semana 6 | Tienda con JavaScript puro: tarjetas generadas con el DOM, carrito y carga de productos con Fetch API |
| Semana 7 | Creación del proyecto React con Vite |
| Semana 8 | Componentes React con `useState`, `useEffect` y props; carrito y carga de productos |
| Semana 9 (EFT) | Navbar, filtro por categoría, agregar y eliminar videojuegos, formulario de contacto validado, footer, Flexbox/Grid, ajustes responsivos y documentación |
